An immersive audio personality module mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** that dynamically plays contextual audio clips and breaths synchronized with the robot's real-time state during intimate interactions.

---

## 🎮 Features

- **Live State Synchronization:** Real-time audio triggering matched to the bot's pleasure, excitation, fingering, and orgasm states.
- **Dynamic Sequence Coroutine:** Structured multi-phase sound sequences managed by an internal supervisor coroutine to avoid overlapping clashing sounds.
- **Categorized Audio:** Over 30 curated OGG sound files organized into breath, soft, normal, intense, and climax tiers.
- Compatible with MDRG version **v0.97.12** (Target: `0.95.5+`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/moan-audio-pm/releases) tab.
