## 🎮 Features

- **Live State Synchronization:** Real-time audio triggering matched to the bot's pleasure, excitation, fingering, and orgasm states.

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/moan-audio-pm/releases) page and download `Moan Audio Personality Module.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Moan Audio Personality Module.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Moan Audio Personality Module/mod.json
   ```
4. Launch the game and equip the **Moan Audio Personality Module** in the bot's module slot.
